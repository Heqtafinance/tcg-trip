# BlueLine

Web app iPhone (PWA) pour suivre la rentabilité des achats TCG en voyage.

- Tableau de bord rouge / orange / vert sur l'ensemble du panier
- Simulateur « je l'achète ? »
- Achats avec photos (ticket + produit), lien Cardmarket généré
- Taux ¥/€ du jour (BCE) et taux douanier mensuel
- Récap douane, export Excel, ZIP des photos, sauvegarde / restauration

Les données restent sur l'appareil (IndexedDB). Ce dépôt ne contient que le code.

Installation : ouvrir l'adresse GitHub Pages dans Safari → Partager → « Sur l'écran d'accueil ».
